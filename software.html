Software / configuración

El puente entre el gesto y la pantalla.

Una herramienta de configuración que permite ajustar los parámetros de respuesta del AirMouse y adaptar la interpretación del movimiento a las preferencias de cada usuario. Desde el software se pueden establecer los valores necesarios para controlar cómo los cambios de orientación detectados por el sensor se traducen en desplazamientos del cursor. Esta parte del proyecto se encuentra actualmente en evolución y forma parte del sistema de personalización del AirMouse.
